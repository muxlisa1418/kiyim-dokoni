# Loyiha xartiyasi (Project Charter)

## 1. Loyiha nomi va muammosi
- Loyiha nomi: Kiyim-kechak do'koni boshqaruv tizimi
- Muammo: Do'konda kiyimlarning o'lchamlari, ranglari, sotuvlari va ombor qoldig'i daftarda yoki tarqoq jadvallarda yuritilgani sababli hisob-kitobda xatoliklar va vaqt yo'qotilishi yuzaga keladi.

## 2. Loyiha pasporti

| Ko'rsatkich | Tavsifi |
| :--- | :--- |
| Maqsad | Kiyimlar hisobi, sotuvlar va ombor qoldig'ini yagona veb-tizimga o'tkazish |
| Natija (MVP) | Brauzerda ishlovchi, login, ombor va kassa bo'limlariga ega ishchi veb-ilova |
| Foydalanuvchilar | Administrator, Sotuvchi-kassir va Omborchi |
| KPI | 3 ta rol uchun ishlaydigan MVP; barcha operatsiyalarni real vaqtda saqlash |
| Xatar | Talablarning o'zgarishi yoki brauzer xotirasi tozalanishi |
| Mas'ul | Muxlisa (Loyiha rahbari va dasturchi) |

## 3. Loyiha qamrovi (Scope)
- Qamrovga kiradigan funksiyalar: Tizimga kirish (Login), mahsulotlar qo'shish/tahrirlash (o'lcham va rang bo'yicha), sotuv (kassa) operatsiyalari, ombor qoldig'i nazorati va hisobotlar.
- Qamrovga kirmaydigan funksiyalar: Mobil ilova (Android/iOS), onlayn bank kartalari orqali to'lov integratsiyasi, shtrix-kod skaneri qurilmasi.

## 4. 4 haftalik taxminiy reja
- 1-hafta: Talablarni yig'ish, muammoni tahlil qilish va loyiha xartiyasini tuzish.
- 2-hafta: Interfeys (UI/UX) dizayni va HTML/CSS sahifalarini yaratish.
- 3-hafta: JavaScript orqali ombor, sotuv va localStorage funksiyalarini yozish.
- 4-hafta: Tizimni sinovdan o'tkazish, GitHub Pages'ga joylash va namoyish etish.

## 5. GitHub Issues (Vazifalar)
- #1 Login sahifasi
- #2 Mahsulotlar va ombor boshqaruvi
- #3 Sotuvlar va hisobotlar bo'limi
