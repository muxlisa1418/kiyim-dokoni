# Kiyim-kechak do'koni boshqaruv tizimi

Ushbu veb-ilova kiyim-kechak do'konidagi mahsulotlar, o'lchamlar, ranglar, sotuvlar va ombor qoldig'ini avtomatlashtirilgan tarzda boshqarish uchun yaratilgan.

## Ishga tushirilgan sayt (Demo)
https://github.io

## Loyiha tuzilmasi
- index.html — asosiy sahifa va interfeys tuzilmasi
- style.css — dizayn va moslashuvchan uslublar
- script.js — tizim mantig'i va localStorage boshqaruvi
- docs/project-charter.md — loyiha xartiyasi hujjati
